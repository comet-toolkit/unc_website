# Uncertainty Metadata Naming Conventions (UNC) Website

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24467473.svg)](https://doi.org/10.5281/zenodo.24467473)

This repository contains the sources files for the [UNC website](https://comet-toolkit.github.io/unc_website/).

## How to Cite

The latest version of the UNC Specification (v0.2) is archived on [Zenodo](https://doi.org/10.5281/zenodo.24467473). Please cite it as:

> Hunt, S., Hassell, D., Embury, O., & De Vis, P. (2026). Uncertainty Metadata Naming Conventions (UNC) Specification (v0.2). Zenodo. https://doi.org/10.5281/zenodo.24467473
